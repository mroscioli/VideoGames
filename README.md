# Games That Last: A New Era of Video Games on Steam

This project analyzes how business models and game design choices influence the success and longevity of video games on Steam.

Using a large dataset of Steam titles, the analysis compares free-to-play and paid games in terms of audience reach, player engagement, and satisfaction, and examines how different game designs (single-player, multiplayer, and hybrid) affect long-term and recent player activity.

The project was developed as part of a data visualization course and combines exploratory data analysis with visual storytelling to highlight key patterns in the contemporary video game industry.

The analysis is fully reproducible and based on publicly available data.
